# 丹炉 · 炼药小游戏

中式修仙炼丹点击小游戏（HTML 原型）：选素材 → 投炉 → 掐时机 → 炼成丹。

灵感来自《旷野之息》烹饪系统 + 抖音锻刀小游戏。设计文档见 [`design/GDD.md`](design/GDD.md)。

## 🎮 玩法

1. **选素材**：从素材栏选择 1~3 种素材（草药/矿物/兽材），点"🔥 开炼"
2. **掐时机**：三段判定（投炉→控火→出锅），指针在刻度条上摆动，在合适位置点击停下
   - 金色区域 = 完美，紫色 = 良好，灰色 = 普通，其余 = 失误
   - **失误 ≥2 段会爆炉**！丹炉偶尔"灵气波动"会让区间偏移
3. **炼成丹**：素材组合命中配方出对应丹药，品阶看判定得分；未知组合炼出随机杂丹
4. **收集图鉴**：解锁新丹方和新素材

## 🚀 运行

```bash
# 方式一：直接双击 index.html 打开（推荐用下面的本地服务器）

```

## 📁 目录结构

```
lingyao/
├── index.html        # 入口
├── style.css         # 中式风格样式
├── js/
│   ├── data.js       # 素材/配方数据（纯数据，Godot 移植 1:1 转换）
│   ├── judge.js      # 判定逻辑（纯函数）
│   ├── game.js       # 游戏状态机（背包/图鉴/流程）
│   ├── ui.js         # DOM 渲染与交互
│   └── main.js       # 入口
├── design/GDD.md     # 设计文档（含 Godot 移植规划）
└── test.js           # 逻辑单测
```

## 🔧 调参

- 判定难度：`js/data.js` 中 `JUDGE_ZONES`（区间）与 `JUDGE_STAGES`（摆动速度）
- 素材/配方：`js/data.js` 中 `MATERIALS` / `RECIPES`（新增素材注意 `unlock` 解锁条件）
